## 🚀 About the project

NexClick Control Studio is a Windows desktop application designed to make mouse-click automation easier to control through a dedicated interface.

The repository includes the Python source code, application icon and scripts for launching and building the program.

## ✨ Features

- Modern custom branding.
- Python source code.
- Installation and launch script.
- Build script with custom application icon.
- Project files available for inspection.

## 📥 Download

Visit the [Releases page](https://github.com/TheKingRetro/NexClick_Control_Studio_v4.0/releases) to see published versions.

A downloadable Windows executable will be provided there when a release is available.

## 🛠️ Installation

1. Download the project files.
2. Read `README.txt` for the installation instructions.
3. Run `INSTALL_AND_LAUNCH.bat` on Windows.

## 🧱 Build from source

The project includes `BUILD_EXE_WITH_ICON.bat` and `NexClick Control Studio.spec`.

Review the installation instructions and required dependencies before building the executable.
